Access to the storage

These are the keys that reach the files, rather than the password that makes them readable. They are a smaller matter than the password, and deliberately held to a lower standard: a key can be withdrawn in a second, where the password can never be changed — changing it would mean starting your backups again from nothing.

What this does not prove

That every disclosure was recorded. Anyone who can read the server's vault file directly reads the password without passing through any of this, and leaves no entry behind. What this record does prove is that the entries in it have not been changed since this computer last looked — which is worth having, and is less than a promise that nobody has ever seen your password.

The storage keys are weaker still. This record says which ones Eumaeus created and which it withdrew, and it checks the storage provider for keys it did not create — but no server here ever sees a request to your bucket, so nobody can say whether any key has actually been used. A key listed as retired is one the provider has confirmed no longer works; a key listed as found is one somebody outside this system holds.
